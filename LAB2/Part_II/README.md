# Часть II. Жадные алгоритмы

Каждая задача находится в отдельной папке `Task1` ... `Task6`, со своими `include/` и `src/`. Сборка всех программ:

## Матроид и обоснование жадного выбора

Алгоритм Радо-Эдмондса применим к задаче максимизации весового независимого множества матроида. Не все перечисленные в условии задачи имеют такую постановку. Ниже приведены корректные основания жадных решений и причины, по которым нельзя приписывать им матроид без дополнительного переопределения задачи.

1. **Степени четверки.** Для неограниченных монет номиналом `1, 4, 16, ...` жадный выбор самой крупной допустимой монеты оптимален: каждые четыре монеты номинала `4^k` можно заменить одной монетой `4^(k+1)`, уменьшая число монет на три. Повторяя замену, получаем представление цифрами основания 4, минимальное по числу слагаемых. Пара `n, m` означает сумму `n` и наибольший доступный показатель `m`. Это задача о точном размене, а не выбор независимого подмножества матроида; например, для ёмкости 4 независимые по сумме множества четырёх монет 1 и одной монеты 4 нарушают аксиому обмена.
2. **Египетские дроби.** На каждом шаге выбирается `1/ceil(den/num)`, то есть наибольшая единичная дробь, не превышающая остаток. После вычитания остаток строго уменьшается, поэтому алгоритм завершается для положительных рациональных чисел. Это последовательное разложение с точным равенством, не задача выбора независимого множества матроида: удаление слагаемого обычно нарушает равенство.
3. **Расписание.** Независимые множества — наборы попарно непересекающихся полуоткрытых интервалов. Они не образуют матроид: множество из двух интервалов `[0,2)`, `[2,4)` и множество из одного `[0,4)` нарушают аксиому обмена. Жадное правило «раньше заканчивающийся интервал» всё же оптимально: первый интервал любого оптимального расписания можно заменить заканчивающимся не позже выбранного, не уменьшая оставшееся время.
4. **Покрытие отрезка интервалами.** Жадно берём среди интервалов, начинающихся не позже текущей границы покрытия, интервал с самым дальним правым концом. Это оптимально по обмену: первый интервал любого покрытия можно заменить выбранным, которое продвигает границу не меньше. Множество решений «полностью покрыть `[L,R]`» не наследственно (удаление нужного интервала может разрушить покрытие), следовательно, это не семейство независимых множеств матроида.
5. **Покрытие точек.** После сортировки ставим отрезок длины `unitlen` от самой левой непокрытой точки. Любое допустимое решение должно накрыть эту точку; сдвиг первого такого отрезка вправо до неё не теряет покрытых точек справа. Повторение даёт оптимум. Семейство наборов отрезков, покрывающих все точки, также не наследственно и не является матроидом. Длина отрезка здесь понимается геометрически: `[x, x + unitlen]`.
6. **Группы детей.** Сортируем детей по возрасту и включаем в группу всех следующих детей, чей возраст не превышает возраст самого младшего в группе на более чем 2 года. Если первая группа оптимального решения начинается с того же самого младшего ребёнка, её границу можно расширить до границы жадной группы, не увеличивая число групп; далее применяется тот же аргумент к остатку. Ограничение на разброс возраста в выбранном множестве само по себе не задаёт матроид: три ребёнка возраста `-2` и два ребёнка возрастов `0` и `2` дают независимые наборы размеров 3 и 2, но ни один ребёнок первого набора нельзя добавить ко второму, не нарушив ограничение.

## Контракты функций

- `powers_of_four(n, m)` возвращает число монет, используя номиналы от `4^0` до `4^m`.
- `egyptian_fractions(num, den)` возвращает знаменатели в `arr`; при `den == 0` и переполнении бросает исключение.
- `schedulemax(reqs)` сортирует заявки по времени завершения и возвращает максимальное количество; соприкосновение концов допускается.
- `covermin(L, R, intervs)` возвращает минимум или `-1`, если покрыть диапазон невозможно.
- `coverpoints(pts, unitlen)` сортирует точки и возвращает минимум отрезков геометрической длины `unitlen`.
- `funparty(kids, nkids)` возвращает группу для каждого исходного элемента в `mapping[i].ngroup`; `mapping[i].nkid` хранит `kids[i].id`. Вызывающий код владеет массивом `mapping` и должен освободить его через `delete[]`.

В примере задания для покрытия точек отрезки `[1,4]` и `[7,10]` не покрывают точку `5`. Для длины 3 пример `[1,3,5,7,9]` требует 3 отрезка, например `[1,4]`, `[5,8]`, `[9,12]`.
