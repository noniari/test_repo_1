# Полевой атлас

Учебный проект интерактивной карты научных экспедиций.

**Текущая версия:** `v0.1 BETA`

**Статус:** первый прототип, работа продолжается.

## Что сделано в v0.1

- Создан каркас сайта на React, TypeScript и Vite.
- Добавлена карта Leaflet с подложкой OpenStreetMap/FOSSGIS.
- На карту нанесены три демонстрационных маршрута в формате GeoJSON.
- Добавлен простой список маршрутов: выбор записи выделяет линию и приближает карту.
- Сохранён адаптивный макет; на этом этапе интерфейс намеренно минимален.

Это демонстрация начала работы, а не готовый каталог экспедиций. Координаты линий пока обобщённые и требуют проверки по источникам.

## Пока не реализовано

- Проверенный каталог экспедиций и ссылки на исторические источники.
- Точки полевых наблюдений и дополнительные геометрии.
- Поиск, фильтры и подробные карточки.
- Автоматические тесты и публичное развёртывание.

## Структура папки

```text
COURSEWORK/
	public/data/expeditions.geojson  # демонстрационные маршруты
	src/
		components/ExpeditionMap.tsx   # карта и линии маршрутов
		types/expedition.ts            # типы GeoJSON
		App.tsx                        # страница и выбор маршрута
		App.css                        # оформление страницы
		index.css                      # базовые стили
		main.tsx                       # запуск React
	package.json                     # зависимости и команды
	README.md
```

Остальные конфигурационные файлы нужны Vite, TypeScript и линтеру.

## Запуск

Требуются Node.js и npm.

```bash
npm install
npm run dev
```

Проверка сборки и стиля кода:

```bash
npm run build
npm run lint
```

## Данные

Маршруты находятся в `public/data/expeditions.geojson`. Используется GeoJSON `FeatureCollection` с геометрией `LineString`. Координаты записываются в порядке `[долгота, широта]`.

## Версии проекта

Промежуточные версии будут отмечать небольшие проверяемые этапы разработки: от `v0.1` до `v0.9`. Версия `v1.0` будет присвоена после проверки данных и основных функций, тестирования интерфейса и подготовки проекта к сдаче.

## Карта

Тайлы предоставляются сервером `tile.openstreetmap.de` проекта FOSSGIS. В приложении отображается атрибуция OpenStreetMap contributors и FOSSGIS. При публикации нужно соблюдать условия и ограничения сервиса тайлов.
