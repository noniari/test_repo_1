# Полевой атлас

Фундамент курсового проекта: интерактивная карта маршрутов и мест наблюдений научных экспедиций. Интерфейс написан на React и TypeScript, карта — Leaflet, данные хранятся в GeoJSON.

## Запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

## Пять этапов разработки

1. **Каркас и модель данных.** Vite, React, TypeScript, типы экспедиции и проверка входного GeoJSON.
2. **Карта и слои.** Подложка OpenStreetMap, маршруты `LineString`, станции `Point`, выбор и фокус карты.
3. **Поиск и фильтры.** Поиск по названию, исследователю и судну; отбор по периоду, региону и научному направлению.
4. **Карточка и адаптивный интерфейс.** Синхронизация карты со списком, детали выбранной экспедиции, состояния загрузки и ошибки.
5. **Проверка и публикация.** Тестирование данных и интерфейса на разных экранах, описание источников, production-сборка и развёртывание.

Текущий фундамент уже включает первый этап и базовые части этапов 2–4. Перед академической публикацией следует проверить точность каждого маршрута и заменить обобщённые демонстрационные линии координатами из выбранных источников.

## Данные

`public/data/expeditions.geojson` — `FeatureCollection` с объектами `Point` и `LineString`. Координаты GeoJSON записываются в порядке `[долгота, широта]`. Поле `sourceNote` отмечает демонстрационные маршруты и не заменяет библиографическую ссылку.

Подложка загружается с `tile.openstreetmap.de` (сервер FOSSGIS); сохраняется атрибуция © OpenStreetMap contributors и © FOSSGIS. Официальный `tile.openstreetmap.org` может блокировать загрузку по правилам использования volunteer-run сервера; CARTO в свою очередь возвращает заглушку с требованием API key. Перед публикацией следует учитывать условия и лимиты выбранного сервиса тайлов.
