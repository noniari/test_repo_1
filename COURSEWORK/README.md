# Карта научных экспедиций

Курсовой проект: **интерактивная веб-карта научных экспедиций**. Проект развивается поэтапно: от базовой карты до атласа с маршрутами, местами наблюдений и справочной информацией.

**Текущая версия: `v0.2 BETA`**

## Реализовано

- Интерактивная карта Leaflet с перемещением и масштабированием.
- Картографическая подложка OpenStreetMap с сервера `tile.openstreetmap.de` проекта FOSSGIS.
- Метрическая масштабная линейка.
- Координаты выбранной точки в панели карты: нажмите на карту, чтобы увидеть широту и долготу.
- Боковая панель слева от карты для будущей информации об экспедициях и участниках. Пока в ней отображается «Скоро».
- Адаптивная раскладка: на очень узких экранах боковая панель располагается над картой.

## Ограничения v0.2

Данные об экспедициях ещё не добавлены: на карте пока нет точек наблюдений и маршрутов. Боковая панель является заглушкой и пока не показывает карточки экспедиций.

## Запуск

Из корня репозитория выполните:

```bash
cd COURSEWORK
python3 -m http.server 8000
```

Затем откройте в браузере <http://localhost:8000>.

## Технологии

- **HTML5 и CSS3** — разметка и оформление.
- **JavaScript** — настройка карты и обработка кликов.
- **Leaflet 1.9.4** — отображение интерактивной карты.
- **OpenStreetMap / FOSSGIS** — растровые тайлы картографической подложки.
- **Python HTTP Server** — локальная раздача статических файлов при разработке.

## Структура проекта

```text
COURSEWORK/
  index.html   # разметка страницы и панели
  styles.css   # оформление и адаптивная раскладка
  app.js       # карта Leaflet и элементы управления
  README.md    # документация проекта
```

## План развития

План предварительный и может уточняться по мере работы.

- **v0.1** — страница с базовой картой-подложкой.
- **v0.2** — масштабная линейка, просмотр координат и панель-заглушка.
- **v0.3** — первые точки наблюдений из GeoJSON.
- **v0.4** — отображение сведений о выбранной точке в боковой панели.
- **v0.5** — добавление маршрутов экспедиций.
- **v0.6** — связь точек и маршрутов с экспедициями.
- **v0.7** — поиск по экспедициям и местам наблюдений.
- **v0.8** — фильтрация по датам и регионам.
- **v0.9** — проверка данных, источников и удобства интерфейса.
- **v1.0** — готовая к демонстрации версия с проверенными данными и основными сценариями.

## Атрибуция карты

Подложка предоставляется сервером `tile.openstreetmap.de` проекта FOSSGIS. На карте отображается атрибуция OpenStreetMap contributors и FOSSGIS.
