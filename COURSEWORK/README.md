# Полевой атлас

Интерактивная веб-карта научных экспедиций, их маршрутов и мест наблюдений.

**Версия:** `v0.1 BETA`

**Статус:** рабочий прототип, развитие продолжается.

## Что уже сделано

- Интерактивная карта на Leaflet с подложкой OpenStreetMap/FOSSGIS.
- Отображение маршрутов экспедиций (`LineString`) и отдельных точек наблюдений (`Point`).
- Перемещение и масштабирование карты, автоматический переход к выбранной экспедиции.
- Поиск по названию, руководителю, судну, региону и направлению исследований.
- Фильтры по региону, научному направлению и периоду.
- Список результатов, синхронизированный с картой, и карточка выбранной экспедиции.
- Обработка состояний загрузки, ошибки и отсутствия результатов.
- Проверка структуры GeoJSON, координат, обязательных свойств и уникальности идентификаторов.
- Адаптивная компоновка для широких и узких экранов.

В демонстрационном наборе сейчас шесть объектов: маршруты экспедиций «Челленджер», «Фрам», «Терра-Нова», «Бигль» и «Вега», а также точка зондирования впадины Челленджера.

## Технологии

- React и TypeScript — компоненты интерфейса и типизация данных.
- Vite — локальный сервер разработки и production-сборка.
- Leaflet и React-Leaflet — интерактивная карта и географические слои.
- GeoJSON — формат хранения демонстрационных данных.
- OpenStreetMap/FOSSGIS — картографическая подложка.
- Lucide — иконки интерфейса.

## Запуск

Требуется Node.js и npm.

```bash
npm install
npm run dev
```

Vite напечатает локальный адрес приложения в терминале.

Проверка production-сборки и lint:

```bash
npm run build
npm run lint
```

## Данные экспедиций

Файл данных: `public/data/expeditions.geojson`. Это GeoJSON `FeatureCollection`; для маршрутов используется геометрия `LineString`, для отдельных мест наблюдений — `Point`.

Координаты записываются в порядке `[долгота, широта]`. Свойства каждого объекта включают идентификатор, название, годы, руководителя, судно, регион, направление исследований, описание, цвет и заметку об источнике.

Текущие линии маршрутов обобщены и предназначены для демонстрации интерфейса. Это не проверенные навигационные треки и не научный первоисточник. Перед сдачей курсовой необходимо сверить координаты и сведения с надёжными публикациями и добавить библиографические ссылки к данным.

## План из пяти этапов

1. **Фундамент проекта — готово.** Настроены Vite, React, TypeScript, зависимости, структура и модель данных.
2. **Карта и геоданные — базовая версия готова.** Отображаются точки и линии; предстоит верифицировать и расширить реальные маршруты.
3. **Поиск и фильтры — базовая версия готова.** Работают поиск и фильтры; возможны дальнейшие улучшения диапазонов дат и удобства.
4. **Карточки и адаптивность — базовая версия готова.** Список связан с картой, есть карточка экспедиции и мобильная компоновка; необходимо проверить интерфейс на реальных устройствах и доработать доступность.
5. **Проверка и публикация — впереди.** Добавить автоматические тесты, проверить источники и сценарии, подготовить публичное развёртывание.

## Атрибуция карты

Подложка предоставляется сервером `tile.openstreetmap.de` проекта FOSSGIS. В интерфейсе указаны OpenStreetMap contributors и FOSSGIS. При публикации приложения необходимо соблюдать условия использования и ограничения сервиса тайлов.
